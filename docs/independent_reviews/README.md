# Independent Assessor Reviews

This directory is reserved for completed independent assessor statements that have explicit permission for public release.

## Publication policy

A review may be included only when:

- the assessor has completed the assigned annotation review;
- the statement is submitted as a final PDF;
- publication permission is recorded;
- attribution preference is clear;
- no private working sheet, email address, signature, or item-level annotation record is exposed without explicit authorization.

Reviews may be published:

- with the assessor's name, role, and affiliation where permission is granted; or
- anonymously where the assessor requests anonymity.

## Excluded material

The public repository does not contain incomplete annotation sheets, private comments, annotation-gap CSVs, individual question identifiers, or private adjudication records.
